## 📦 What's Inside?

### 1. 🛒 Full-Stack eCommerce Store (`ecommerce-app/`)
A complete, production-ready online store built with Node.js, Express, and MySQL.
* **Tech Stack:** Node.js, Express.js, MySQL (Sequelize), Vanilla JS, Tailwind CSS
* **Key Features:** 
  * Full authentication system with Email OTP verification
  * Stripe Payment Gateway integration for checkout
  * Dynamic product catalog with filters & cart management
  * Full Admin Panel to add/edit products and manage orders

---

### 2. ⚡ VidSnag - Modern Video Downloader (`VidSnag/` & `advanced downloader/`)
A sleek, high-speed web application for downloading videos from YouTube and other video platforms.
* **Tech Stack:** Next.js 14, TypeScript, Tailwind CSS, `yt-dlp`
* **Key Features:**
  * Clean, responsive UI with light/dark mode
  * Instant video info extraction (thumbnails, formats, resolutions)
  * Supports MP4 video and MP3 audio downloads
  * Built-in ad containers & mobile-friendly layout

---

### 3. 🖼️ AI Image Background Remover (`Image_background_remover/`)
A quick Python CLI tool that uses machine learning to remove background from images automatically.
* **Tech Stack:** Python, `rembg`, OpenCV, Pillow
* **Usage:** Drop an image in the folder and run `python bg_remover.py` to get a clean transparent PNG in seconds.

---

### 4. 🎬 YouTube Downloader Flask (`YouTube-Video-Downloader-Flask/`)
A Python Flask web app to paste YouTube URLs and download videos directly.
* **Tech Stack:** Python, Flask, PyTube / yt-dlp

---

## 🛠️ How to Run Any Project

Each folder is self-contained. To run any specific project:

1. Navigate to its folder:
   ```bash
   cd ecommerce-app   # or VidSnag, Image_background_remover, etc.
   ```
2. Follow the setup instructions inside that specific project's `README.md` or install dependencies:
   * **For Node/Next.js projects:** `npm install` && `npm run dev`
   * **For Python projects:** `pip install -r requirements.txt` && `python main.py`
